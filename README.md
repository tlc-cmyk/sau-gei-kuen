# 收機拳

用一拳打走行人手上嘅手機——一隻喺瀏覽器即玩、以手機直立為主嘅街頭小品。純屬漫畫式惡作劇，拳頭唔會整傷任何人。

線上試玩：<https://tlc-cmyk.github.io/sau-gei-kuen/>

## 點玩

1. 打開 `index.html`（或上面嘅 GitHub Pages 連結），撳「開始」。
2. 用手指或滑鼠**撳螢幕**：拳頭會由畫面頂部、對準你撳嘅位置打落行人路。虛線係瞄準線。
3. 打中行人手上嘅**手機（同持機嗰隻手）**先計一分，顯示「N 支」。空著手、或者只係撞到身體，唔計分。
4. 同一拳只要幾支機排成一列，可以一次過打走。太慢或者太快連打唔到——分數旁邊嘅圈圈係充能，充滿先可以再出拳。
5. 畫面下面嘅「股票」係假指數，純屬搞笑；只要街上仲有人低頭睇機就會亂跳，收得愈多，指數有機會稍微收復。
6. 一局大約 60 秒。完場會見到今次收成、評級，同埋存在呢部裝置嘅自我最佳。

標題、遊戲同結果畫面都有「聲音：開／關」。建議用手機直立玩；桌面瀏覽器用滑鼠一樣得。

## 操作一覽

| 操作 | 作用 |
| --- | --- |
| 撳／撳一下螢幕 | 拳頭由上面打落，瞄準該位置的垂直線 |
| 打中手機 | +1 支，手機飛走，行人嚇一跳然後抬頭 |
| 打中空身手人 | 唔計分，最多輕輕一震 |
| 打空（只係打到地上） | 揚起一陣塵 |
| 分數旁嘅圈圈 | 出拳冷卻／充能 |
| 「聲音：開／關」 | 靜音或開聲 |
